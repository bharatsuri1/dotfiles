# Antinote

## Role

Instant temporary scratchpad for transient text, calculations, and clipboard-derived notes.

## Recommendation

Retain with an explicit temporary-data role and a habit of promoting durable material to Obsidian.

## Modern baseline

Use one global shortcut, enable automatic backups appropriate to ephemeral notes, avoid retaining sensitive clipboard material, and keep the scratchpad intentionally short-lived. Recent releases add built-in rolling database backups.

## Host and legacy audit

Antinote is installed with standard preferences; no legacy tracked configuration exists.

## Configuration ownership

Bootstrap the app. Note database, rolling backups, clipboard-derived content, license, and preferences remain local/private. Track only the role, shortcut, retention, and promotion policy.

## Integration notes

Antinote is capture/scratch; Obsidian is durable knowledge and Raycast may be command entry. Use the closest built-in Vesper-like palette rather than copying private note data.

## Open decisions

- Decide global shortcut and maximum practical retention behavior.
