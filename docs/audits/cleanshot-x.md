# CleanShot X

## Role

Primary screenshot, annotation, scrolling-capture, and short screen-recording tool.

## Recommendation

Retain if its annotation/cloud workflow is actively used; otherwise reassess against macOS capture and the already-installed Shottr.

## Modern baseline

Choose one global capture shortcut owner, minimize automatic cloud upload, and grant Screen Recording access only to the retained tool. CleanShot licenses and Cloud accounts are machine/account bootstrap concerns.

## Host and legacy audit

CleanShot X is installed with standard preferences; legacy Raycast configuration referenced its extension. No portable exported settings were found.

## Configuration ownership

Document installation and activation, but keep the license, Cloud account, upload history, recordings, screenshots, and Library preferences local. Track only a concise shortcut/behavior specification unless CleanShot provides a supported export.

## Integration notes

Resolve overlap with Shottr and macOS screenshots. Raycast actions can expose capture commands. Vesper can guide annotation colors if user presets are supported.

## Open decisions

- Retain CleanShot versus Shottr; decide whether Cloud upload is enabled.
