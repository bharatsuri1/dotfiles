# fd

## Role

Provide fast, ergonomic filename and directory discovery for interactive shell, FZF, and editor workflows.

## Recommendation

Retain. Use upstream defaults and add only a small global ignore file if repeated noise is observed.

## Modern baseline

fd uses smart case, ignores hidden and Git-ignored paths by default, supports `.fdignore`/`.ignore`, and exposes parallel execution. Upstream documents direct FZF integration. Avoid globally forcing unrestricted search because that defeats safe and performant defaults.

## Host and legacy audit

fd is installed. No dedicated configuration or legacy global ignore file was found.

## Configuration ownership

Homebrew owns installation. Stow may own `$XDG_CONFIG_HOME/fd/ignore`. Project-specific exclusions belong in `.gitignore`, `.ignore`, or `.fdignore` with the project. No cache or state needs tracking.

## Integration notes

Use fd as FZF's filename source and Ripgrep for content search. If hidden files are enabled for interactive search, explicitly exclude `.git/`. Colors should derive from `LS_COLORS`, potentially generated by Vivid; Vesper applies indirectly through that shared palette.

## Open decisions

- Whether FZF should include hidden but non-ignored files by default.
- Whether a global ignore file is necessary at all.
