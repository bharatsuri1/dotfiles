# Plaud

## Role

Companion and cloud workflow for Plaud recording hardware, transcription, and meeting notes.

## Recommendation

Retain only for the hardware-backed meeting workflow; treat recordings/transcripts as sensitive records with explicit retention.

## Modern baseline

Record only with appropriate notice/consent, review cloud processing and regional storage choices, enable strong account security, and delete recordings according to a defined retention policy. Legal consent requirements vary by jurisdiction and context.

## Host and legacy audit

Plaud is installed with a desktop preference domain. No legacy configuration exists.

## Configuration ownership

Bootstrap the official app. Account tokens, device identifiers, recordings, transcripts, summaries, contacts, caches, and preferences stay private/service-owned. The tracker should hold only installation, consent, export, backup, and retention policy.

## Integration notes

Overlaps with FluidVoice and ChatGPT voice, but Plaud's durable meeting/recorder role is distinct. Approved summaries may be promoted to Obsidian. Vesper is irrelevant.

## Open decisions

- Define consent, retention, export, and deletion policy.
